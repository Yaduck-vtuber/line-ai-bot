系統偵測到您輸入的 LINE 金鑰無效或此店家代號已被鎖定保護。

✅ Token 複製常見 3 大錯誤自我檢查：

1. 誤把 Channel ID 當成 Channel Secret：Channel ID 是純數字，而 Channel Secret 是 32 碼「英文+數字」。

2. Access Token 複製不完整：Token 長達 172 碼且結尾通常有 = 號，請點擊 LINE 後台旁邊的 Copy 按鈕。

3. 店家代號 (tenant_id) 已被他人註冊鎖定：為防止帳號被覆蓋竄改，若要更新同一店家的設定，請確保輸入與首次開通完全一致的 Channel Secret。
