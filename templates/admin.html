💡 1. 如何重新綁定您的 LINE 接收「專人客服通知」？
現在只要打開您的手機 LINE，直接對這隻機器人輸入 /綁定店長 四個字，系統就會在 1 秒內把您的 LINE 設為店長通知接收人！綁定後可點下方「📨 發送專人通知測試」驗證。
💡 2. 如何用這隻原本的 LINE 帳號自己填看看表單並測試回覆？
展開下方 default 店家的 「📝 直接填寫／修改這隻 LINE 帳號的店家問答表單（知識庫）」，填入您想測試的規定並按儲存；只要客人問了沒寫在表單裡的問題，AI 一律不會亂猜，並會立即轉接通知到您的 LINE！
🧪 如何實測客戶「查詢購買紀錄」與「申請退費」流程？
在右側確認測試信箱後點擊「🧪 建立一筆模擬付費訂單」，即可立即在下方產生測試訂單；接著點頂部「👁️ 以前台會員視角開啟官網」，就能親手點擊「申請取消訂閱 / 退費」並回到這裡一鍵核銷退費！

2. Google 帳號一鍵登入設定 (Google OAuth Client ID — 選填)

📌 Google Cloud Console 設定小抄（對應您的畫面）：

1. 目標對象 (User Type)：請選擇 「外部 (External)」 並按下一步（選外部才能讓所有一般 Gmail 客人登入；完成後在「目標對象」頁點一下「發布應用程式」即可開放所有人免審核登入）。

2. 建立用戶端 (Clients)：應用程式類型選 「網頁應用程式 (Web application)」，在「已授權的 JavaScript 來源」填入：https://line-ai-bot-530475721837.asia-east1.run.app

3. 複製產生出來的 xxxx.apps.googleusercontent.com 貼入下方並儲存，首頁的 Google 按鈕就會直接彈出官方 Google 帳號選擇視窗！

3. 自動寄信信箱設定 (Gmail 16 碼應用程式密碼 — 選填・不填也能正常營運！)

❓ 什麼是「Gmail 16 碼應用程式密碼」？（此欄為選填，現在留空完全不影響網站與 LINE 機器人運作！）

• 為了保護您的個人信箱安全，Google 規定「網站自動寄信程式」不能填您平常登入 Gmail 的密碼，而是要填一組由 Google 專門簽發的「16 個英文字母專用代號」。

• 日後若想啟用自動寄信怎麼拿？只要登入您的 Google 帳戶 ➔ 搜尋「應用程式密碼 (App passwords)」➔ 輸入名稱「SmartHost」點建立，Google 就會給您 16 個英文字母貼在這裡（不需要時留空即可）。
