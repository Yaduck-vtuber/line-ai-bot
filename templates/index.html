常見問題 (FAQ)

Q1. 我完全不懂寫程式，真的可以自己開通嗎？

可以！您只需要到 LINE 官方帳號開發者後台複製兩串金鑰（Channel Secret 與 Access Token），貼到我們的開通頁面，系統就會自動完成驗證並給您專屬 Webhook 網址，全程不超過 3 分鐘。

Q2. 如果我不小心把 Google 試算表的某格刪掉，機器人會壞掉嗎？

絕對不會！我們內建「3 層防呆保護機制」：第一列標題設有唯讀保護，且若您不小心將某個欄位（如退房時間）留白，後端會自動帶入安全預設備援值，確保 AI 永不當機。

Q3. LINE Notify 已經結束服務了，客人要求找真人客服時我怎麼收到通知？

我們提供獨家「A+B+C 複合轉接通知設定」：支援（A）官方 LINE Messaging API 直接推播至店長個人 LINE、（B）Telegram Chat ID 免費無上限即時推播備援、以及（C）緊急通知 Email 同步寄送，並附上客人的 LINE 名稱與「3 句話問題摘要卡」！
