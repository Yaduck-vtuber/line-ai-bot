i LINE 官方後台 4 步按鈕名稱對照教學

STEP 1

啟用 Messaging API

進入 LINE 官方帳號後台，點右上角齒輪 「設定」 ➔ 左側選單 「Messaging API」 ➔ 點擊綠色按鈕 「啟用 Messaging API」。

1. LINE Official Account Manager ↗ 2. LINE Developers Console ↗
STEP 2

複製 Channel Secret

打開 LINE Developers Console 點選您的頻道 ➔ 點上方分頁 「Basic settings」 ➔ 滑到最底下找到 「Channel secret」 ➔ 點擊 「Copy」。

STEP 3

發行 Channel Access Token

切換至上方分頁 「Messaging API」 ➔ 滑到最底部找到 「Channel access token (long-lived)」 ➔ 點擊 「Issue」 ➔ 點擊 「Copy」。

STEP 4

貼上 Webhook 並開啟開關

送出下方表單取得專屬網址後，在同一個 「Messaging API」 分頁找到 「Webhook settings」 ➔ 點 「Edit」 貼上並按 「Update」 ➔ 開啟 「Use webhook」 綠色開關！

🛡️ 必看！防止「LINE 內建罐頭機器人」與「AI 管家」搶話打架的黃金 3 開關：

為了避免客人傳訊息時，LINE 內建的預設罐頭訊息（「感謝您的來信，目前無法個別回覆...」）跳出來跟 AI 管家同時回覆，請至 LINE Official Account Manager 右上角齒輪 「設定 (Settings) ➔ 回應設定 (Response settings)」 確認以下 3 個開關：

1. 回應模式 (Response mode)：
設為 「聊天 (Chat)」（讓您隨時可用手機 App 看對話並真人插話）
2. 自動回應訊息 (Auto-response)：
務必設為 「停用 (Disabled / 關閉)」（關掉內建罐頭才不會跟 AI 打架！）
3. Webhook：
務必設為 「啟用 (Enabled / 開啟)」（讓 AI 管家 24H 幫您秒回！）

💡 怎麼填寫最不會出錯？推薦填寫以下 6 大黃金欄位（Google 試算表亦同）：
1. 【營業時間與入住/服務時間】：寫明幾點到幾點、公休日、最晚入場或入住時間。
2. 【商品 / 房型 / 服務價目表】：寫明完整項目名稱與對應金額（勿只寫「依現場為主」）。
3. 【店家不接受之事項與禁忌】：例如「全館禁菸、不接待寵物、不提供加床、禁止訪客」。
4. 【交通地址與停車規定】：地址、大眾運輸出口、有無特約停車場及收費標準。
5. 【付款方式與退改規定】：可接受的付款方式（現金/刷卡/轉帳）、取消或改期規則。
