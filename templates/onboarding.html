STEP 1

啟用 Messaging API

進入 LINE 官方帳號後台，點右上角齿轮 「設定 (Settings)」 ➔ 左側選單 「Messaging API」 ➔ 點擊綠色按鈕 「啟用 Messaging API」。

1. LINE Official Account Manager ↗ 2. LINE Developers Console ↗
STEP 2

複製 Channel Secret

打開 LINE Developers Console 點選您的頻道 ➔ 點上方第一個分頁 「Basic settings（チャネル基本設定）」 ➔ 滑到最底下找到 「Channel secret」 ➔ 點擊右側 「Copy（コピー）」 按鈕。

STEP 3

發行 Channel Access Token

切換至上方分頁 「Messaging API（Messaging API設定）」 ➔ 滑到最底部找到 「Channel access token (long-lived)」 ➔ 點擊 「Issue（発行）」 按鈕 ➔ 點擊 「Copy（コピー）」 複製。

STEP 4

貼回 Webhook 並開啟開關

送出下方表單取得專屬網址後，在同一個 「Messaging API」 分頁中間找到 「Webhook settings」 ➔ 點 「Edit（編集）」 貼上並按 「Update（更新）」 ➔ 開啟 「Use webhook（Webhookの利用）」 綠色開關！

統一安全開通表單（HTTPS 加密防竄改保護）

⚠️ 請輸入 3~30 碼英文小寫、數字或底線 (3~30 lowercase alphanumeric/underscore).

⚠️ 請輸入有效的 Email 格式 (Invalid email).

❌ Channel Secret 應為 28～40 碼英數字串（位於 Basic settings / チャネル基本設定 分頁）。

✅ Token 複製常見 3 大錯誤自我檢查：

1. 誤把 Channel ID 當成 Channel Secret：Channel ID 是純數字，而 Channel Secret 是位於 Basic settings (チャネル基本設定) 底部的 32 碼「英文+數字」。

2. Access Token 複製不完整：請在 Messaging API (Messaging API設定) 底部點擊 Issue (発行) 後，按旁邊的 Copy (コピー) 按鈕完整複製。

3. 店家代號 (tenant_id) 已被鎖定保護：為防止帳號被外人覆蓋竄改，若要更新同一店家的設定，請輸入與首次開通一致的 Channel Secret。
