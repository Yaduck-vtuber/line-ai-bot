✅ Token 複製常見 3 大錯誤自我檢查：

1. 誤把 Channel ID 當成 Channel Secret：Channel ID 是純數字，而 Channel Secret 是 32 碼「英文+數字」。

2. Access Token 複製不完整：Token 長達 172 碼且結尾通常有 = 號，請點擊 LINE 後台旁邊的 Copy 按鈕，勿手動框選。

3. 貼上時前後多出空白或換行：重新貼上後系統將自動為您去除頭尾空白。
